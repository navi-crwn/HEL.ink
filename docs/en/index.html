Features

  • Single Sign-On (HOP ID)

    One login covers all HOP apps. Signed tickets and chained logout keep every session consistent.

  • Unified App Launcher

    Switch between LinkHop, BioHop, PixelHop, and NoteHop in one click from anywhere.

  • Shared Database Architecture

    One MySQL or SQLite database stores all credentials, with dedicated migration tables per application.

  • Robust Account Security

    Argon2id hashing, TOTP two-factor authentication, Cloudflare Turnstile bot protection, and email verification.

  • Live Service Watchdog

    Automated health checks and latency monitoring across all member applications without secret exposure.

  • Central Family Assets

    Official brand marks, Inter, Instrument Serif and JetBrains Mono fonts, and 3D assets served from hel.ink with SRI hashes.

  • Fine-Grained API Tokens

    Generate scoped service tokens for seamless cross-app communication and developer automation.

  • Completely Self-Hostable

    100% free and open source. Run the hub alone or host the entire HOP ecosystem on a single VPS.

Frequently asked questions

What is HOP ID?

HOP ID is the central authentication service for the HOP family. Creating one account lets you sign into LinkHop, BioHop, PixelHop, and NoteHop.

Can I run the hub without other apps?

Yes. The hub can run standalone as an authentication and directory service, but it is at its best when paired with HOP apps.

How does single logout work?

Logging out from the hub terminates your local session and dispatches chained logout signals to connected apps.

Is HEL.ink open source?

Yes, HEL.ink and all public HOP apps are released under the permissive MIT license.
