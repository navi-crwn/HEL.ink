Satu akun HOP untuk setiap aplikasi.

Fitur Utama

  • Single Sign-On (HOP ID)

    Satu login mencakup seluruh aplikasi HOP. Tiket bertanda tangan dan logout berantai menjaga konsistensi sesi.

  • Peluncur Aplikasi Terpadu

    Berpindah antara LinkHop, BioHop, PixelHop, dan NoteHop dalam satu klik dari mana saja.

  • Arsitektur Basis Data Bersama

    Satu basis data MySQL atau SQLite menyimpan kredensial dengan tabel migrasi terpisah per aplikasi.

  • Keamanan Akun Tangguh

    Hashing Argon2id, autentikasi dua faktor TOTP, proteksi bot Cloudflare Turnstile, dan verifikasi email.

  • Pengawas Layanan Langsung

    Pemeriksaan kesehatan otomatis dan pemantauan latensi di semua aplikasi tanpa pembocoran rahasia.

  • Aset Keluarga Terpusat

    Ikon resmi, font Inter, Instrument Serif dan JetBrains Mono, serta aset 3D dilayani dari hel.ink dengan hash SRI.

  • Token API Berlingkup

    Buat token layanan berlingkup untuk komunikasi antar-aplikasi dan otomatisasi pengembang.

  • Sepenuhnya Dapat Dipasang Sendiri

    100% gratis dan open source. Jalankan hub sendiri atau pasang seluruh keluarga HOP di satu VPS.

Pertanyaan yang sering diajukan

Apa itu HOP ID?

HOP ID adalah layanan autentikasi terpusat untuk keluarga HOP. Satu akun bisa dipakai di LinkHop, BioHop, PixelHop, dan NoteHop.

Bisakah menjalankan hub tanpa aplikasi lain?

Ya. Hub dapat berjalan mandiri sebagai layanan akun, namun manfaat maksimal dirasakan bersama aplikasi keluarga HOP.

Bagaimana cara kerja logout tunggal?

Keluar dari hub akan mengakhiri sesi lokal dan mengirimkan sinyal logout berantai ke aplikasi yang terhubung.

Apakah HEL.ink bersifat open source?

Ya, HEL.ink dan semua aplikasi publik keluarga HOP dilisensikan di bawah lisensi MIT.
