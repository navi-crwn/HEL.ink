Características

  • Inicio de sesión único (HOP ID)

    Un solo inicio de sesión para todas las apps HOP. Tickets firmados y cierre de sesión encadenado.

  • Lanzador unificado de aplicaciones

    Cambia entre LinkHop, BioHop, PixelHop y NoteHop con un solo clic.

  • Arquitectura de base de datos compartida

    Una base de datos MySQL o SQLite almacena identidades con tablas de migración dedicadas por app.

  • Seguridad de cuenta robusta

    Hashing Argon2id, autenticación 2FA TOTP, protección Turnstile y verificación de correo.

  • Monitor de salud en vivo

    Verificaciones de salud automáticas y métricas de latencia sin exponer credenciales.

  • Activos centrales de la familia

    Marcas oficiales, fuentes familiares y mosaicos 3D servidos desde hel.ink con hashes SRI.

  • Tokens de API con permisos granulares

    Genera tokens con ámbitos definidos para la comunicación entre aplicaciones y automatización.

  • Completamente autohospedable

    100% libre y de código abierto. Ejecuta el hub solo o todo el ecosistema en un único VPS.

Preguntas frecuentes

¿Qué es HOP ID?

HOP ID es el servicio de autenticación central para la familia HOP. Una cuenta sirve para todas las apps.

¿Puedo usar el hub sin las otras apps?

Sí. El hub puede funcionar de forma independiente como proveedor de cuentas y directorio.

¿Cómo funciona el cierre de sesión único?

Cerrar sesión en el hub destruye tu sesión local y envía señales de cierre encadenadas a las apps conectadas.

¿Es HEL.ink de código abierto?

Sí, HEL.ink y todas las apps públicas de HOP tienen licencia MIT.
