HOP · 家族中心与账户门户

一个 HOP 账户，畅行所有应用。

HEL.ink 是 HOP 的账户门户和家族目录。只需使用 HOP ID 登录一次，即可在 LinkHop、BioHop、PixelHop 和 NoteHop 之间无缝切换。

访问 hel.ink 打开 Hub 在 GitHub 查看

基于 MIT 许可证的免费开源软件。

功能特性

  • 单点登录 (HOP ID)

    一次登录覆盖所有 HOP 应用。签名凭证与链式登出确保会话一致。

  • 统一应用启动器

    随时随地一键在 LinkHop、BioHop、PixelHop 和 NoteHop 间切换。

  • 共享数据库架构

    共享单个 MySQL 或 SQLite 数据库存储身份，各应用独立的迁移账本避免冲突。

  • 严格的安全防护

    Argon2id 哈希、TOTP 双重认证、Cloudflare Turnstile 防护与邮箱验证。

  • 实时看门狗监测

    自动健康监测与延迟监控，零密钥泄露。

  • 集中式家族资产

    官方图标、家族字体（Syne、Plus Jakarta Sans）和 3D 浮动卡片由 hel.ink 提供 SRI 支持。

  • 细粒度 API 令牌

    生成带权限范围的令牌，用于应用间通信与开发者自动化。

  • 完全开源与自建

    100% 自由开源。可独立运行 hub，也可在单个 VPS 上部署整个 HOP 生态。

自建您的 Hub

Hub 运行在标准现代 PHP 基础设施上。

git clone https://github.com/navi-crwn/HEL.ink.git
cd HEL.ink
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate
npm install && npm run build
php artisan serve

环境要求

PHP 8.3+、Composer、Node.js 22+，以及 SQLite 或 MySQL/MariaDB。

SSO 配置

在 .env 中配置 HOP_SSO_SECRET（32 位以上字符）以为家族应用签名凭据。

共享数据库配置

设置 DB_MIGRATIONS_TABLE=migrations_hub 以便在与 LinkHop 共享数据库时保持迁移记录独立。

查看 .env.example 获取详尽的配置说明。

常见问题

什么是 HOP ID？

HOP ID 是 HOP 家族的集中认证系统。拥有一个账户即可使用所有 HOP 应用。

我能单独运行 Hub 吗？

可以。Hub 可以作为独立的账号与目录服务运行，但配合 HOP 应用体验最佳。

单点登出如何工作？

从 Hub 登出将销毁本地会话，并向所有已连接的应用发送链式登出信号。

HEL.ink 是开源的吗？

是的，HEL.ink 和所有公开的 HOP 应用均采用宽松的 MIT 许可证。
