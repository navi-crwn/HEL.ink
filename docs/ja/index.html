HOP · ファミリーハブ & アカウントポータル

すべてのアプリに、ひとつの HOP アカウント。

HEL.ink は HOP のアカウントポータルおよびディレクトリです。HOP ID で一度ログインすれば、LinkHop、BioHop、PixelHop、NoteHop をシームレスに利用できます。

主な機能

  • シングルサインオン (HOP ID)

    1 回のログインですべての HOP アプリに対応。署名付きチケットと連鎖ログアウトで安全を維持。

  • 統合アプリランチャー

    どこからでもワンクリックで LinkHop、BioHop、PixelHop、NoteHop を行き来できます。

  • 共有データベース構造

    1 つの MySQL または SQLite でアカウントを保持し、アプリ別のマイグレーション台帳で競合を防止。

  • 堅牢なアカウントセキュリティ

    Argon2id ハッシュ、TOTP 二要素認証、Cloudflare Turnstile 保護、メール確認に対応。

  • ライブサービスウォッチドッグ

    秘密情報を漏らすことなく、ファミリーアプリ全体の稼働状況と応答速度を自動監視。

  • 集中管理されたファミリー資産

    公式マーク、フォント、3D フローティングタイルが SRI ハッシュ付きで hel.ink から配信されます。

  • きめ細やかな API トークン

    アプリ間通信や開発者自動化のためのスコープ付きサービストークンを発行可能。

  • 完全なセルフホスト対応

    100% 無料かつオープンソース。Hub 単体での運用も、単一の VPS 上で HOP 全体を構築することも自由です。

よくある質問

HOP ID とは何ですか？

HOP ID は HOP ファミリーの中央認証サービスです。1 つのアカウントで全アプリにアクセスできます。

他のアプリなしで Hub を単体実行できますか？

はい。Hub は単体のアカウント・ディレクトリサービスとしても動作しますが、HOP アプリと併用することで真価を発揮します。

シングルログアウトはどのように機能しますか？

Hub からログアウトするとローカルセッションが破棄され、接続中の各アプリへ連鎖ログアウト信号が送信されます。

HEL.ink はオープンソースですか？

はい、HEL.ink およびすべての公開 HOP アプリは MIT ライセンスで提供されています。
