HOP · Hub familial et portail de comptes

Un seul compte HOP pour toutes vos applications.

HEL.ink est le portail de comptes et le répertoire de la famille HOP. Connectez-vous une fois avec votre HOP ID et passez en toute fluidité entre LinkHop, BioHop, PixelHop et NoteHop.

Visiter hel.ink Ouvrir le Hub Voir sur GitHub

Logiciel libre et open source sous licence MIT.

Fonctionnalités

  • Authentification unique (HOP ID)

    Une seule connexion pour toutes les applications HOP avec tickets signés et déconnexion en chaîne.

  • Lanceur d'applications unifié

    Passez de LinkHop à BioHop, PixelHop et NoteHop en un clic depuis n'importe où.

  • Base de données partagée

    Une base MySQL ou SQLite stocke les identités avec des tables de migration dédiées par application.

  • Sécurité robuste des comptes

    Hachage Argon2id, 2FA TOTP, protection Cloudflare Turnstile et vérification des e-mails.

  • Surveillance des services en direct

    Vérifications de santé automatisées et suivi de la latence sans exposition de secrets.

  • Ressources centrales de la famille

    Logos officiels, polices et cartes 3D flottantes servis depuis hel.ink avec hachages SRI.

  • Jetons d'API avec permissions ciblées

    Générez des jetons pour la communication inter-applications et l'automatisation des développeurs.

  • Entièrement auto-hébergeable

    100 % gratuit et open source. Lancez le hub seul ou hébergez tout l'écosystème sur un unique VPS.

Hébergez votre propre hub

Le hub s'exécute sur une infrastructure PHP moderne standard.

git clone https://github.com/navi-crwn/HEL.ink.git
cd HEL.ink
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate
npm install && npm run build
php artisan serve

Prérequis

PHP 8.3+, Composer, Node.js 22+ et SQLite ou MySQL/MariaDB.

Configuration SSO

Définissez HOP_SSO_SECRET (32+ caractères) dans votre .env pour signer les tickets en toute sécurité.

Configuration de la base de données

Configurez DB_MIGRATIONS_TABLE=migrations_hub pour isoler le journal de migration lors du partage de base.

Consultez .env.example pour découvrir l'ensemble des options de configuration.

Foire aux questions

Qu'est-ce que HOP ID ?

HOP ID est le service central d'authentification de la famille HOP. Un seul compte ouvre l'accès à toutes les applications.

Puis-je utiliser le hub sans les autres applications ?

Oui. Le hub peut fonctionner de manière autonome comme fournisseur d'identité et annuaire.

Comment fonctionne la déconnexion unique ?

Vous déconnecter du hub détruit votre session locale et transmet un signal de déconnexion aux apps connectées.

HEL.ink est-il open source ?

Oui, HEL.ink et toutes les applications publiques de HOP sont publiées sous licence MIT.
